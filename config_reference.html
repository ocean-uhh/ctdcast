Configuration reference

The configuration reference is split across the pages below. This page is kept so existing :doc:`config_reference` and :ref:`config_reference` links keep resolving; it is deliberately outside the toctree (:orphan:) because the pages it points to are listed in the sidebar directly.

  • config.yaml — every config.yaml field: paths, output, generate, sensors, display.

  • Cruise metadata (cruise_info) — the cruise_info block: identity, platform, people, institutions, embargo.

  • ctd_sections.yaml — every ctd_sections.yaml field: sections and timeseries.

  • Data files (netCDF) — the netCDF files ctdcast reads and writes.
