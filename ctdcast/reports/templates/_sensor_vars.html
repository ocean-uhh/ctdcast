{# The three families of sensor variables in a compiled profiles file: what each carries, and their tables. Shared by the netCDF inventory page and the SBE sensors page. #} {% import "_nc_tables.html" as nc %} {% macro explanation() %}

The file records its sensors in three families of variables:

  • SENSOR_<TYPE>_<SERIAL> — one dimensionless variable per physical device, e.g. SENSOR_CONDUCTIVITY_3120. It holds no data; its attributes are the device's provenance: model, maker, serial, calibration date, the datcnv slope/offset and the configuration block as recorded.
  • sensor_<role> — per profile, the name of the SENSOR_* variable that filled that role, e.g. sensor_conductivity_2 = SENSOR_CONDUCTIVITY_3120. A change along the profiles is a sensor swap. Where a preferred pair or oxygen is declared, sensor_<role>_preferred names the device chosen for the plain composite.
  • sensor_channel_<role> — per profile, the raw CNV acquisition channel that role's sensor was wired to (−1 where unused). A change with the same device is a re-cabling.
