=======================
Configuration reference
=======================

The configuration reference is split across the pages below. This page is kept
so existing ``:doc:`config_reference``` and ``:ref:`config_reference``` links
keep resolving; it is deliberately outside the toctree (``:orphan:``) because the
pages it points to are listed in the sidebar directly.

- :doc:`config_yaml` — every ``config.yaml`` field: paths, output, generate,
  sensors, display.
- :doc:`cruise_metadata` — the ``cruise_info`` block: identity, platform, people,
  institutions, embargo.
- :doc:`ctd_sections` — every ``ctd_sections.yaml`` field: sections and
  timeseries.
- :doc:`data_files` — the netCDF files ctdcast reads and writes.
